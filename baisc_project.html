Chrome Extension project

I developed a Chrome Extension that provides real-time URL safety validation using a machine learning model. The extension automatically detects the active tab’s URL whenever a user opens a website and sends it to a backend Flask API, where an ML model analyzes various security-related features such as HTTPS usage, domain age, URL length, and presence of suspicious patterns. Based on the prediction, the extension displays an immediate alert—similar to professional security tools like McAfee—warning users if the website is malicious or unsafe. The goal of this project is to enhance user security by offering a seamless, automatic browser-level protection layer without requiring manual checks. I am also extending support for Firefox to make the tool cross-browser compatible.

Car Price prediction Project

I developed a Car Price Prediction web application that uses machine learning to accurately estimate the market value of used cars based on various features such as brand, model, year, fuel type, mileage, engine capacity, and transmission. The project includes a complete data pipeline for preprocessing, feature engineering, and model training, where I experimented with multiple regression algorithms and hypertuned the best model using MLflow. The final model is deployed through a Flask web interface, allowing users to enter car details and instantly receive a predicted price. The application is designed to be production-ready, with cloud-based model storage and support for containerized deployment using Docker and Kubernetes, making it efficient, scalable, and easy to integrate into real-world systems.

Stock price prediction Project

I developed a Stock Price Prediction system that uses machine learning and time-series forecasting techniques to predict future stock prices based on historical market data. The project involves data preprocessing, feature engineering, and experimentation with models such as LSTM, ARIMA, and ensemble regressors to capture both short-term fluctuations and long-term trends. The system analyzes key indicators like opening price, closing price, volume, moving averages, and volatility to generate accurate predictions. A Flask-based web interface allows users to input a stock symbol and view predicted prices along with visualized trends. The project is designed with scalability in mind, supporting cloud-based deployment and model tracking using MLflow, making it suitable for educational, analytical, and financial decision-support applications.

Network security Project

I developed a Network Security URL Classification system that uses machine learning to identify malicious, phishing, and suspicious URLs in real time. The project involves extracting and engineering security-related features such as URL length, presence of IP addresses, HTTPS usage, redirection patterns, special characters, domain age, and other threat indicators. Multiple classification algorithms were trained and evaluated, and the best-performing model was integrated with a Flask API for live prediction. This system can be used by browsers, security tools, or backend services to detect harmful URLs before users interact with them. The project emphasizes reliability, scalability, and modern MLOps practices, using MLflow and DagsHub for experiment tracking, version control, and model deployment.
